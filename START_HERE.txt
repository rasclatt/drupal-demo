💡 ESSENTIAL COMMANDS

Start/Stop:
  docker-compose up -d                    ← Start all containers
  docker-compose down                     ← Stop all containers
  docker-compose ps                       ← Show container status

Logs:
  docker-compose logs -f drupal_web       ← Watch Drupal logs
  docker-compose logs drupal_db           ← View database logs

Access:
  docker exec -it drupal_web bash         ← Access container shell
  docker exec -it drupal_db mysql ...     ← Access MySQL

Drush (Drupal Command Line):
  docker exec drupal_web drush --root=/var/www/html/web status
  docker exec drupal_web drush --root=/var/www/html/web cache:rebuild
  docker exec drupal_web drush --root=/var/www/html/web en module_name

(See README_SETUP.md for many more commands)

❓ TROUBLESHOOTING

Containers won't start?
  → Check if ports 80, 443, 3306, 8081 are available
  → Run: docker-compose logs
  → Restart Docker

Installer not loading?
  → Wait 60 seconds for containers to initialize
  → Check: docker-compose ps (all should show "healthy")
  → Clear browser cache

Can't connect to database?
  → Verify drupal_db container is running
  → Check settings.php has correct config
  → Test manually: docker exec drupal_db mysql -u drupal -pdrupal_password

Changes not showing?
  → Clear Drupal cache: docker exec drupal_web drush --root=/var/www/html/web cache:rebuild
  → Hard refresh browser: Ctrl+Shift+R (or Cmd+Shift+R on Mac)

For more help, see README_SETUP.md or INSTALL_GUIDE.md
